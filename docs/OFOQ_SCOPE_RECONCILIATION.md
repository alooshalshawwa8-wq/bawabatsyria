## معيار العد المستقبلي

1. يُسجل كل قسم بمعرّف ثابت وعنوان ومالك وظيفي.
2. تُسجل كل أداة مستقلة في سجل أدوات موحد بمعرّف ثابت، ووصف إدخال/إخراج، ومصدر بيانات، وحالة تشغيل.
3. تُفصل الأدوات الحقيقية عن عناصر التنقل، والواجهات المشتركة، والقوالب، والاختصارات.
4. لا يُحتسب العنصر أداة مكتملة قبل اختبار المسار الأساسي، والمدخلات غير الصالحة، وحالة فشل المصدر، والهاتف.
5. تُربط عناصر النطاق التاريخي بعناصر الفهرس الحالي عندما تتوفر قائمة أصلية موثقة؛ وتُوسم الإضافات الجديدة صراحة.
6. تُحدّث هذه الوثيقة مع أي إضافة أو دمج، دون حذف وظائف قائمة.
