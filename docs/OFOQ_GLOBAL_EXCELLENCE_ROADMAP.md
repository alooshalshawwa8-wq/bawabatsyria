# أُفُق — مبادئ التطوير والجودة العامة

## الرؤية العامة

تطوير منصة عربية متعددة الخدمات، سهلة الاستخدام، سريعة، آمنة، وقابلة للتوسع، مع بناء منتجات عملية تحقق قيمة واضحة للمستخدمين.

## مبادئ المنتج

1. تقديم وظائف أصلية ومفيدة، واحترام حقوق الملكية الفكرية.
2. عدم اعتبار الميزة مكتملة قبل عملها واختبارها.
3. الحفاظ على الخدمات الأساسية المتاحة مجاناً خلال المرحلة التجريبية.
4. استخدام معايير مفتوحة وتقنيات قابلة للصيانة.
5. إبقاء مفاتيح الخدمات والأسرار في بيئة الخادم فقط.
6. توضيح مصدر البيانات وتاريخ تحديثها عند استخدام بيانات متغيرة.
7. حماية خصوصية المستخدم، وعدم مزامنة البيانات الشخصية دون حاجة وموافقة واضحة.
8. جعل العربية وRTL وإمكانية الوصول والهاتف وتقليل الحركة جزءاً من معايير القبول.

## بوابات الجودة

- **الأساس:** نشر مستقر، ملفات محلية سليمة، اختبارات متصفح، وعدم وجود أخطاء واجهة حرجة.
- **المنتجات:** وظيفة واضحة لكل قسم، وبيانات موثوقة عند الحاجة، وحالة مكتملة أو مخططة معلنة بوضوح.
- **التنقل:** بحث مفيد، وصول بلوحة المفاتيح، وحفظ السياق المحلي وفق إعدادات المستخدم.
- **الذكاء الاصطناعي:** حدود تكلفة واستخدام، تخزين مؤقت مناسب، معالجة أخطاء المزود، وعدم كشف المفاتيح.
- **المعلومات المباشرة:** إظهار المصدر والتوقيت وعمر التخزين المؤقت.
- **التجربة:** تصميم متجاوب، قابلية قراءة، وإمكانية تعطيل الحركة.
- **الأمان:** مصادقة وتفويض صحيحان، حماية المدخلات، مراجعة الصلاحيات، ونسخ احتياطي قابل للاستعادة.
- **الإطلاق:** اختبارات رحلة مستخدم كاملة ومراجعة جاهزية الخدمات قبل الإعلان عن اكتمالها.

## معيار الإنجاز

لا تُقاس الجودة بعدد الملفات أو التعديلات؛ بل بالوظائف التي تعمل، والاختبارات التي تنجح، واستقرار الخدمة، ورضا المستخدم، والقيمة التجارية المثبتة.

التفاصيل الداخلية وخطط التوسع غير المنشورة محفوظة في سجل المؤسس الخاص، وليست جزءاً من هذه الوثيقة العامة.
