- لم يُجرَ اختبار اختراق شامل؛ نجاح الفحوص الآلية لا يغني عنه.

## الخدمات التجارية والدفع

- المنصة ما زالت في وضع التجربة المجانية.
- الفوترة معطلة وفرض الميزات المدفوعة معطل.
- أسعار مزود الدفع غير مربوطة بالخطط، ولا توجد اشتراكات أو طلبات دفع مسجلة.
- أضيف حاجز خادمي مزدوج: لا تُعرض إمكانية الدفع ولا يُنشأ Checkout إلا إذا كانت مفاتيح الدفع مهيأة وكان إعداد الإطلاق التجاري في قاعدة البيانات على وضع الإنتاج مع تفعيل الفوترة وفرض الميزات المدفوعة.
- لم تُنفذ معاملات حقيقية. لا تُعتبر رحلة الدفع end-to-end مكتملة قبل إعداد مفاتيح اختبار مزود الدفع وإجراء اختبارات sandbox ثم اعتماد المالك.

## بيانات كرة القدم

- مزود البيانات الخارجي ما زال محظوراً بسبب مشكلة حساب لدى المزود.
- يظل الحظر مفعلاً في قاعدة البيانات؛ لا تُرسل طلبات إلى المزود ولا تتم محاولة تجاوز تعليق الحساب.
- تم تحديث فحص حالة الخدمة بحيث يعلن حالة الحظر بوضوح، ويتجنب فحص حالة المزود الخارجي عندما يكون الحظر فعالاً.
- لا تعود البيانات المباشرة حتى استعادة حساب المزود أو اعتماد مزود بديل ومفاتيح مصرح بها.

## Personal workspace continuity — 2026-11-13

- Favorites and recently visited section IDs (ofoq_personal_space_v1) are now included in local and optional cloud Operations Hub backups.
- Only known section IDs are captured when the catalog is available; snapshots enforce limits of 78 favorites and 12 recent visits, reject duplicates and malformed values.
- Restore validates the optional personal-space payload and attempts to roll back the Operations Hub data and personal-space key if either write fails.
- Existing backup files without the optional personal-space field remain compatible.
- This is manual backup/restore, not live or automatic cross-device synchronization. Favorites and visit history reach the cloud only when the user explicitly creates an optional cloud backup.
- Static contract checks now protect this integration from regressions.
- Source change: operations-hub.js, commit e36a3c8d4f16bb274360c679f98849b4da5116d4.
